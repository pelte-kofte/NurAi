# Roadmap

## Near-to-Mid Term Themes
- Ramadan mode
- Religious dates/special messages
- Prayer preparation
- Daily sunnah
- Audio reflections
- Widgets v2
- Live activity improvements
- Premium content expansion

## Direction
- Expand Duada by deepening spiritual usefulness, not by adding noisy feature volume.
- Favor features that support remembrance, prayer rhythm, Quran continuity, and gentle companionship.

## Constraints
- New features should preserve calmness.
- Features should feel Islamic in purpose and wording.
- System-level features like widgets, notifications, and live activities should remain lightweight and trustworthy.
