# Release Checklist

## Before Release
- Confirm version bump.
- Run `flutter analyze`.
- Run localization check.
- Run premium check.
- Run widgets check.
- Run notifications check.

## Device Validation
- TestFlight smoke test.
- Real device test.
- Verify critical paths on an actual iPhone before release when iOS-specific behavior is involved.

## Store Readiness
- App Store metadata/screenshots check.
- Ensure screenshots match the current UI.
- Ensure metadata language matches Duada tone and copy standards.

## Focus Areas
- Prayer Times state and location flows
- Quran reading continuity
- Reflection and Companion integrity
- Premium purchase and restore flows
- Widgets and shared payload freshness
- Notification permission and delivery behavior
